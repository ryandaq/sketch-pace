# Drawing practice app landscape

Reviewed 2026-10-15 from official product pages, help pages, and course descriptions. This is a broad feature scan, not an exhaustive inventory or a hands-on comparison. A feature appearing in an app is evidence that the approach exists, not proof that it improves skill. Sketch Pace's **Exploration Lab** implements original, local versions of the patterns listed below; it does not copy lessons, reference images, models, or code from these products.

## What this suggests for Sketch Pace

1. **Many short modes:** Repetition can target different visual operations: motor control, contour matching, spatial construction, observation, memory, shading and idea generation.
2. **Adjustable support:** Trace, side-by-side copy, grid transfer, memory reveal and blind drawing can use the same reference while changing how much help is visible.
3. **Feedback matched to the task:** Geometric drills can use approximate automated scores; thumbnail ideas and blind contour benefit more from a saved self-rating and side-by-side comparison. The Lab labels which kind of feedback it gives.
4. **Pacing variety:** Timed bursts, untimed study, warm-up countdowns, daily prompts, mixed queues and replay all alter how a session feels without requiring a new scoring scale.
5. **User control:** The app keeps uploaded images on the local device for the current session, lets the user export drawings, and isolates experimental records from the established Practice/Test metrics.

The Lab is an idea collection for review. Its approximate scores are prototypes, not validated measurements of artistic development.
